# M. Arun — Portfolio

This is a standalone, responsive portfolio website. Open `index.html` in a browser; it does not need a build step or external packages.

## Files

- `index.html` — page content
- `styles.css` — responsive layout and visual theme
- `main.js` — gallery filters, photo lightbox, and mobile navigation
- `assets/` — portrait, X Robotics logo, 24 learning photos, and 14 student achievement photos
- `PUBLISH.md` — steps to publish the site with GitHub Pages

Contact details and experience are taken from the resume image. The home street address has been left out of the public page. The project summaries are concise descriptions based on the resume.
